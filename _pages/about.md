I'm **Marko Durasic**, a Senior Software Engineer based in Taipei, Taiwan. I specialize in **Go backend systems, cloud engineering, infrastructure, and production reliability**, with more than a decade of professional software-engineering experience.

My current role is **Senior Software Engineer at Otto Group one.O**, where I work on backend and cloud systems. My recent engineering work includes Go services, AWS infrastructure, Infrastructure as Code, CI/CD, observability, performance, and reliability. I previously worked as a **Technical Lead at Innova Solutions** and held senior backend engineering roles at **FAZZ, XRSPACE, and Acer**.

I care about how systems behave under real production constraints: failures, latency, deployment risk, changing requirements, operational cost, and the trade-offs that appear after the demo is over.

## Engineering focus

- **Go backend engineering** — services, APIs, concurrency, performance, maintainable system design
- **Cloud engineering** — AWS, infrastructure, security, observability, cost, and reliability
- **Infrastructure & DevOps** — Infrastructure as Code, Terraform, AWS CDK, Docker, Kubernetes, CI/CD, GitHub Actions
- **Technical leadership** — architecture decisions, code reviews, mentoring, workshops, and developer enablement
- **Distributed systems** — event-driven services, integrations, caching, failure handling, and production operations

## Selected engineering work

My professional work has included modernizing cloud deployment infrastructure with **AWS CDK**, improving backend latency through **ElastiCache/Valkey**, building and operating Go services, and designing cloud-based microservice systems.

Earlier in my career, I rewrote a CloudHSM-related service from **C++ to Go** as part of an open-source effort, with a substantial throughput improvement. I have also worked across e-commerce, payment, storage, Linux systems, automation, and enterprise integration.

## Open source and public technical work

I publish code and technical experiments on [GitHub](https://github.com/marko-durasic), including work around **Go, backend systems, AWS, cloud tooling, automation, and AI-assisted developer tools**.

I use open source as more than a portfolio. Publishing working software makes technical claims inspectable: people can read the code, run it, criticize it, and improve it.

See **[Projects & Open Source](/projects/)** for selected work.

## Writing, teaching, and developer education

I earned a **Master of Science in Computer Science from National Taiwan Normal University (NTNU)** in Taipei. During my time at NTNU, I also worked as a Graduate Teaching Assistant, helping students with programming and data-structure coursework.

I continue that teaching thread through technical writing, workshops, learning tools, and public explanations of engineering topics. My **[Writing](/blog/)** focuses on practical engineering rather than theory detached from production constraints.
